<a id="tokengatematchmode"></a>

## TokenGateMatchMode

How a channel/category's tokengate address is matched against a wallet's held assets

| Value | Description |
|-------|-------------|
| `0` | Only the wallet holding this exact NFT satisfies the gate |
| `1` | Any wallet holding any asset from the collection at this address satisfies the gate |

<a id="tokengatevisibility"></a>

## TokenGateVisibility

How token-gated channels/categories appear to members who do not satisfy the gate

| Value | Description |
|-------|-------------|
| `0` | Gated channels are visible with a lock icon to non-qualifying members |
| `1` | Gated channels are hidden entirely from non-qualifying members |
